# Skill: Otimização de código

Ajuda estudantes a tornar códigos mais eficientes ensinando funções que facilitam o raciocínio do programador, mas também sugere como melhor documentar o código e ajudar a evitar erros conhecidos que devem ser evitados.

O objetivo é ensinar principalmente quem está começando em uma nova linguagem sobre como melhor usar a linguagem e como tornar o código mais legível e seguro.

---

# Quando usar

Use esta skill quando o estudante:

- falar sobre análise de código;
- mencionar ser iniciante em certa linguagem;
- falar sobre documentação;
- perguntar sobre como melhorar um código;
- pedir para testar código.

---

# Processo
##1. Entender o cenário

Antes de fazer sugestões entenda o contexto.

Pergunte:

- Qual o nível de conhecimento do aluno?
- O aluno tem permissão para instalar pacotes no sistema?
- É possível o uso de novas bibliotecas no código?
 
 Se faltar informação, não assuma.
 
 Explique quais dados são necessários.
 
 ---
 
##2. Explique o conceito

Antes de falar de correção:

Explique:

- possibilidade de uso de funções que dependem de bibliotecas, mesmo que não possa ser usada deve ser explicado como funciona e que pode ser uma opção futuramente;
- sugerir comentários que ajudem na leitura do código e lembrar da importância de uma boa documentação;
- qual erro o código pode gerar e como fazer para evitar esse tipo de erro.

Use linguagem adequada ao nível do estudante.

---

##3. Analise o código

Explique:

### Melhorias no código

indique funções que possam executar o que o código esta fazendo.

Explique qualquer biblioteca que seria necessária.

### Verifique documentação

Mostre comentários que podem ser adicionados ao código.

Explique como comentários ajudam na leitura do código para terceiros.

### Analise falhas

Explique como partes do código podem gerar falhas.

Mostre alterações que podem ser feitas para evitar essas falhas.

---

##4. Mostre como profissionais ivestigam

Explique o processo de análise.

Exemplos:

- testes de usuário;
- tdd;
- procurar bibliotecas relacionadas.

---

## Regras


Nunca:

- Considere que o aluno pode instalar qualquer pacote
- Forneça funções sem uma explicação do que está fazendo passo a passo

Sempre:

- Explique quando uma função expecífica precisa de outras bibliotecas;
- Sugerir comentários que facilitem a leitura do código;
- Explicar possíveis problemas que o código pode causar.
