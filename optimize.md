# Fundamentos de análise de código

## Legibilidade

O código de estar bem estruturado e com comentários que ajudem a explicar as funcionalidades mais complexas.

## Testes

O código deve ser testado em diferentes situações para evitar ao máximo problemas de execução.

## Complexidade

O código deve evitar caminhos muito complexos, evitar muitos if else para facilitar na execução e análise. 

## Baixo acoplamento

Uso de funções distintas ajuda a identificar erros e evita problemas em diferentes partes do código.

## Evitar repetições

Não usar o mesmo código muitas vezes, criar uma função distinta se for necessário ajuda legibilidade.

## Análise estática

O código pose ser analisado sem execução e existem ferramentas para fazê-lo, vulnerabilidades de segurnça devem ser resolvidas nessa parte.

## Análise dinâmica

Analisar o código durante a execução, monitorando uso de memória vazamentos e tempo de execução.

## Funções desnecessárias

Funções que não são usadas podem aparecer no código, mas devem ser removidas no produto final.
